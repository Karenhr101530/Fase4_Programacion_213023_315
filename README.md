# Fase4_Programacion_213023_315
Sistema Integral de Gestión de Clientes, Servicios y Reservas - UNAD

Curso: Programación (213023)
Grupo: 213023_315
Fase 4: Prácticas simuladas

Descripción

Proyecto colaborativo desarrollado en Python para la empresa ficticia Software FJ. El sistema permitirá gestionar clientes, servicios y reservas mediante programación orientada a objetos.

Funcionalidades previstas

Registro y validación de clientes.

Gestión de reservas de salas, alquiler de equipos y asesorías especializadas.

Creación, confirmación y cancelación de reservas.

Cálculo de costos de los servicios.

Manejo de excepciones y registro de errores.

Pruebas de operaciones válidas e inválidas.

Desarrollo colaborativo

Cada integrante desarrollará su parte del proyecto en una rama de GitHub. Posteriormente, se integrarán los aportes y se realizarán pruebas del funcionamiento general.
